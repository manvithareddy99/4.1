## 4. How to Enable GitHub Pages (Hosting Steps)
1. Go to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &rarr; **Branch**:
   * Select branch: `main`
   * Select folder: `/ (root)`
3. Click **Save**.
4. The page will be automatically built and served at `https://manvithareddy99.github.io/4.1/`.
